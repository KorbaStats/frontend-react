# Projekt inżynierski — analiza wpływu pogody na statystyki piłkarskie

Aplikacja webowa do analizy zależności między warunkami pogodowymi a statystykami meczowymi.
W trakcie realizacji.

## Stack
- React, TypeScript, Vite — frontend
- Node.js, Express, PostgreSQL — backend (osobne repo)

## Uruchomienie
```bash
npm install
npm run dev
```
